# やり取りを日本語化するには

* 右上の自分のアイコン -> settings
* setting項目から　Agetnts -> Knowledge を選択
* ここに独自ルールを設定できるので以下のようなルールを設定


- 私とのやり取りは常に日本語で行ってください。
- 思考の説明、提案、質問、エラー解説などはすべて日本語で記述してください。
- コミットメッセージ、PRのタイトル・本文も日本語で記述してください。
- ただし、シェルコマンドやコード本体は変更せず、英語のままで構いません。
- コード内のコメントは日本語でかまいません。
- 技術用語（pull request, branch, commit など）は無理に翻訳しなくて構いません。



# environmentにはpersonal と teamがある

例えば、ユーザーがteamに所属している状態で、新しくrunを作成する時にpersonalのenvironmentを指定するとエラーになる。
その場合はenvironmentをteamに移動する。

ただし、ユーザーがteamかpersonalかをどこで見るかはわかっていない。

# 公式ドキュメントの入り口
メインのドキュメントサイト: docs.warp.dev
ここがOzとWarpの全機能を網羅する起点で、Warp(モダンターミナル)とOz(クラウドエージェント・オーケストレーションプラットフォーム)の両方をカバーしています。 Warp

# 初心者向けクイックスタート(おすすめ順)
## 1. Cloud Agent Quickstart(約10分)
docs.warp.dev/agent-platform/cloud-agents/quickstart
最初のクラウドエージェントを約10分で実行する方法を学べるガイド。リモート環境でエージェントを動かし、自動化・スケジューリング・チームコラボレーションが可能になるもの。最初に読むべきページです。 Warp

## 2. Oz CLI Quickstart(約5分)
docs.warp.dev/reference/cli/quickstart
Oz CLIで最初のクラウドエージェントを5分以内に立ち上げるためのガイド。CLIのインストール、認証、最初のローカルエージェント実行、MCPサーバーの接続方法までカバー。CLI派の方はこちら。 Warp

## 3. Oz Web App ガイド
docs.warp.dev/agent-platform/cloud-agents/oz-web-app
Warpやコマンドラインを使わずブラウザだけでクラウドエージェントを起動・管理できるWebインターフェース。モバイル対応なので、どこからでも管理可能。インストール不要で試したい方向け。 Warp


# 発展的な使い方
## スケジュール実行(cronのような定期実行)
Scheduled Agents Quickstart - 毎週GitHubのバグレポートをトリアージするエージェントを設定する例を、CLIやカスタムコード不要でWebアプリだけで構築できる方法を解説。 Warp

## プラットフォーム全体の理解
Oz Platform docs - CLI、API/SDK、オーケストレーション、環境、可観測性など、Ozのアーキテクチャ全体を理解できます。

## Cloud Agents Overview
docs.warp.dev/agent-platform/cloud-agents/overview - クラウドエージェントが何で、いつ使うべきかについての概要。イベントへの反応、観測可能性、並列性が必要なケースなどの判断基準を解説。 Warp

# おすすめの学習順序(個人開発者向け)
私のおすすめは次の順番です:

1. ブログ記事でコンセプトを把握 → "Introducing Oz"
1. Web App で手を動かしてみる → ブラウザだけで体験
1. Cloud Agent Quickstart で本格的に環境構築
1. 慣れてきたら CLI/SDK で自動化を作り込む

最初はWebアプリで試して、何ができるか体感してから、自分のワークフローに合わせてCLIやSDKに進むのが挫折しにくいと思います。
何か具体的にやってみたいユースケース(例: PRレビューの自動化、定期的なドキュメント更新、複数リポジトリの一括変更など)があれば、それに沿って深掘りできるドキュメントもご紹介できますよ。
